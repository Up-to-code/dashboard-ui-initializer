# Reusable UI Patterns

## Workspace Header

Use for every channel workspace. Include channel name, connection state, environment, primary action, and local tabs.

## Health Summary Strip

Use for operational status before details. Include active conversations, AI resolution rate, failed handoffs, and knowledge sync state.

## Inspector Rail

Use when users need context while working in a table or conversation. Keep it 320px to 380px wide and tied to the selected object.

## Publish Bar

Use for AI settings, automation builders, and knowledge changes. Show draft state, last published time, reviewer when relevant, and publish action.

## Empty State

Use when the user has no data or no filtered results. Explain the missing object, why it matters, and one next action.

## Audit Timeline

Use for settings changes, automation runs, handoffs, and knowledge indexing. Timeline items should include actor, timestamp, object, action, and result.

## Conversation Split View

Left: conversation list. Center: transcript. Right: customer, AI, and routing context. Collapse right context first on smaller screens.
