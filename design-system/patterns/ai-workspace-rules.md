# AI Workspace Rules

Each connected channel behaves like its own workspace.

## Workspace Model

A channel workspace contains:

- Conversations.
- AI settings.
- Automations.
- Analytics.
- Integrations.
- Knowledge.
- Team access.

## AI Workflow Organization

Use this sequence:

1. Define agent identity.
2. Add instructions.
3. Connect knowledge.
4. Configure tools and automations.
5. Set escalation rules.
6. Test against real scenarios.
7. Publish and monitor.

## Rules

- Always show draft versus published state.
- Keep test panels close to configuration.
- Show what changed before publish.
- Make escalation paths visible.
- Treat knowledge sync and tool permissions as first-class status.
- Avoid "magic" labels when a precise system state exists.
