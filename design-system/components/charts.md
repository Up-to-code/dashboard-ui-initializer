# Charts

Charts are supporting UI only.

## Rules

- Maximum one major chart per page.
- Prefer summaries, deltas, and tables over chart-heavy dashboards.
- Use charts only for trends, distribution, and anomaly detection.
- Avoid rainbow colors.
- Use minimal grids and axes.
- Do not chart data that has fewer than three meaningful points.

## Recommended Types

- Line chart for response volume or resolution trend.
- Bar chart for channel comparison.
- Small sparkline for metric cards.
- Donut charts only when the parts are few and operationally meaningful.

## Palette

Use primary blue for the main series, slate for secondary comparison, and semantic colors only for success/warning/danger states.
