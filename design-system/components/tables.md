# Tables

Tables are the default pattern for operational comparison.

## Use Tables For

- Conversations requiring triage.
- Automations and run history.
- Knowledge sources.
- Team members and access.
- Integrations and channel connections.

## Anatomy

- Toolbar with search/filter/action.
- Header row.
- Dense body rows.
- Status and metadata columns.
- Row action menu.
- Pagination or infinite sentinel.

## Rules

- Row height: 44px to 56px.
- Keep primary identity in the first column.
- Put status before secondary metadata when status changes workflow.
- Avoid zebra stripes; use borders and hover states.
- On mobile, collapse secondary columns into expandable row detail.
