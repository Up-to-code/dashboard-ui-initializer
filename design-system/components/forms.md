# Forms

Forms configure infrastructure and AI behavior, so they must be explicit and forgiving.

## Anatomy

- Section title.
- Short explanatory copy when risk is high.
- Label.
- Input.
- Helper text.
- Error text.
- Save/cancel area.

## Rules

- Group fields by user intent, not database shape.
- Use inline validation for formatting and required fields.
- Use submit validation for cross-field dependencies.
- Keep destructive settings behind confirmations.
- Show whether changes are saved, unsaved, publishing, or failed.
- Prefer toggles for binary settings and segmented controls for small mode sets.

## AI Forms

Prompt and instruction fields need test affordances nearby. Knowledge source forms should show sync state, last indexed time, and failure reason.
