# Branding

The brand should feel infrastructural, calm, and precise.

## Voice

- Direct.
- Specific.
- Quietly confident.
- Operational.

## Visual Identity

- Navy, blue, white, slate, and soft blue.
- Small channel color markers.
- Minimal shadows.
- Stable layout rhythm.
- No purple, neon, glassmorphism, or decorative gradients.

## Product Metaphor

"An operating system for AI communication infrastructure."

This means navigation should feel architectural, configuration should feel safe, and monitoring should feel clear.

## Writing Rules

- Prefer verbs that describe system behavior: connect, route, publish, sync, resolve, escalate.
- Avoid inflated AI copy: magic, supercharge, unleash, revolutionary.
- Status text should be factual: "Knowledge sync failed", "Automation published", "WhatsApp disconnected".
