# Dashboard Rules

Dashboards are operational surfaces, not poster walls.

## Hierarchy

1. Current workspace/channel health.
2. Items requiring action.
3. Throughput and trend summaries.
4. Recent activity.
5. Configuration shortcuts.

## Rules

- Show summaries before charts.
- Use one major chart maximum per page.
- Avoid equal-weight cards for unrelated metrics.
- Make alerts specific and actionable.
- Keep page controls close to the data they affect.
- Use tables when users need to compare, route, filter, or audit.
- Use cards for repeated entities such as channels, automations, knowledge sources, and integration connectors.

## Dashboard Density

Use compact line heights and restrained padding. A premium infrastructure product should feel organized, not sparse for its own sake.
