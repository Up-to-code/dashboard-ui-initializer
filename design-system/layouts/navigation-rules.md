# Navigation Rules

Navigation should make channel context impossible to lose.

## Depth

- Maximum primary depth: 2 levels.
- Use tabs for peer views inside the same object.
- Use breadcrumbs only for deep object paths such as channel > conversation > handoff.

## Patterns

- Sidebar: durable product areas.
- Topbar: search, command menu, notifications, profile.
- Tabs: local modes such as Overview, Conversations, Automations, Settings.
- Command menu: jump, create, search, and quick actions.

## Rules

- Never make settings the dumping ground. Settings must be grouped by operational mental model.
- Route names should match user jobs: "Conversations", "Automations", "Knowledge", "Analytics", "Integrations", "Team".
- Use clear active states on sidebar and tabs at the same time.
