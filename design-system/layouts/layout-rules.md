# Layout Rules

The product is an operating system for AI communication infrastructure. Layouts must support repeated work, fast scanning, and safe configuration changes.

## Dimensions

| Element | Size |
| --- | --- |
| Expanded sidebar | 264px |
| Collapsed sidebar | 72px |
| Topbar | 56px |
| Content max width | 1280px |
| Desktop gutter | 32px |
| Tablet gutter | 24px |
| Mobile gutter | 16px |
| Default grid gap | 16px |
| Dense grid gap | 12px |

## Page Structure

Use this order:

1. Workspace context and page title.
2. Primary action row.
3. Health or summary strip.
4. Main work surface.
5. Secondary diagnostics or history.

## Information Flow

- Left side answers "where am I?"
- Top area answers "what needs attention?"
- Center area supports the main operational task.
- Right side may hold inspectable context, never generic filler.

## Density

Dashboards should be dense but not cramped. Prefer fewer, stronger panels over many equal cards. Every block needs an operational reason: monitor, configure, compare, route, or resolve.
