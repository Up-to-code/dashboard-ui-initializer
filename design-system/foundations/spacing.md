# Spacing System

Base unit: 4px.

Spacing is strict so dashboards remain comparable across channels and teams.

| Token | Value | Use |
| --- | --- | --- |
| `space.1` | 4px | Icon-text gap, tight inline status |
| `space.2` | 8px | Control groups, compact row gaps |
| `space.3` | 12px | Dense card rows, sidebar item padding |
| `space.4` | 16px | Default component gap, compact cards |
| `space.5` | 20px | Standard card padding |
| `space.6` | 24px | Section header gap, page blocks |
| `space.8` | 32px | Desktop page gutters, major groups |
| `space.10` | 40px | Wide dashboard section separation |
| `space.12` | 48px | Empty states, onboarding blocks |
| `space.16` | 64px | Rare page-level breathing room |

## Usage Rules

- Use 16px as the default internal rhythm.
- Cards use 20px padding, or 16px for dense operational panels.
- Page gutters are 32px desktop, 24px tablet, 16px mobile.
- Adjacent controls use 8px gaps.
- Section groups use 24px to 32px gaps.
- Do not invent intermediate values unless aligning to an external primitive.
