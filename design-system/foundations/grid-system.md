# Grid System

The grid supports dense operational pages with clear hierarchy and predictable comparison.

## Desktop Grid

- 12 columns.
- 16px default gap.
- 12px dense gap for tables and compact monitoring surfaces.
- Max content width: 1280px.
- Gutter: 32px.

## Tablet Grid

- 8 columns.
- 16px gap.
- Gutter: 24px.
- Sidebar collapsed by default.

## Mobile Grid

- 4 columns.
- 12px to 16px gap.
- Gutter: 16px.
- One primary task per vertical section.

## Common Layouts

| Pattern | Columns |
| --- | --- |
| Summary metric strip | 3 or 4 equal columns |
| Main + inspector | 8 + 4 |
| Table + right context | 9 + 3 |
| Configuration form | 7 + 5 help/test panel |
| Analytics trend + summaries | 8 + 4 |

## Rules

- Align page headers, toolbars, and content to the same grid.
- Avoid masonry layouts. Operational data should be stable and comparable.
- Do not create more than three competing horizontal zones on one page.
- When content density increases, reduce visual decoration before reducing information.
