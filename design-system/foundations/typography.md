# Typography

Primary font: Inter.

The system is compact and operational. Typography should help users scan, compare, and act without visual noise.

## Scale

| Role | Size | Line Height | Weight | Usage |
| --- | --- | --- | --- | --- |
| Display | 40 | 48 | 600 | Rare overview moments, onboarding only |
| Page title | 28 | 36 | 600 | Workspace and major page headers |
| Section title | 20 | 28 | 600 | Main dashboard sections |
| Card title | 16 | 24 | 600 | Panel headers and row titles |
| Body | 14 | 20 | 400 | Default interface copy |
| Body small | 13 | 18 | 400 | Dense descriptions, table metadata |
| Label | 12 | 16 | 500 | Field labels, nav labels, table headers |
| Caption | 11 | 14 | 500 | Timestamps, helper labels, counters |

## Rules

- Use `400`, `500`, and `600` only.
- Page titles should describe the operational object: "WhatsApp Conversations", "Website Chat Automations", "Knowledge Base".
- Labels use sentence case unless matching a proper product name.
- Avoid oversized headings inside dashboards. A dense app should not feel like a landing page.
- Metadata should be smaller, not lighter than readable contrast allows.
- Keep letter spacing at `0`.
