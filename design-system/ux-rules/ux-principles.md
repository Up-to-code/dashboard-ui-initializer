# UX Principles

## Clarity Over Theater

Users operate business communication infrastructure. The interface should reduce doubt, not impress them with decoration.

## Context Is Durable

The active channel workspace must remain visible through navigation, configuration, and analytics. This prevents cross-channel mistakes.

## Configuration Is Auditable

AI behavior changes can affect real conversations. Show status, owner, timestamps, versioning, and publish state where relevant.

## Summaries Before Detail

Expose the operational answer first, then let users drill into evidence. This reduces cognitive load on busy support and ops teams.

## Empty States Teach The Next Action

Empty states should explain what is missing, why it matters, and the smallest next action. They should not be playful filler.

## AI Is A Workflow, Not A Mascot

AI surfaces should organize prompt behavior, knowledge sources, routing rules, escalation, testing, and deployment. Avoid magic language when a concrete system state is available.
